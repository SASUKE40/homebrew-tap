# SASUKE40 Homebrew Tap

Homebrew casks for apps from [SASUKE40](https://github.com/SASUKE40).

## Lexa

[Lexa](https://github.com/SASUKE40/Lexa) is a small Grammarly alternative for macOS.

To install Lexa, type this command:

```sh
brew install --cask sasuke40/tap/lexa
```

To update Lexa, type this command:

```sh
brew upgrade --cask lexa
```

You must have macOS 26 (or a newer version). Apple did not notarize Lexa. When you open Lexa for the first time, go to **System Settings → Privacy & Security**. Then click **Open Anyway**.
